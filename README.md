# HTML Assignment

## 📌 About
This repository contains my HTML assignment as part of the **Data Science and Visualization (DSV)** subject.

HTML (HyperText Markup Language) is the standard markup language used to create and structure web pages. It uses different tags and elements to organize content such as text, images, links, tables, and forms.

## 🎯 Objectives
- Understand the basics of HTML.
- Learn HTML tags and elements.
- Create and structure web pages.
- Add headings, paragraphs, images, and hyperlinks.
- Create tables and forms.
- Understand HTML page structure.

## 🛠️ Tools & Technologies
- HTML5
- Visual Studio Code
- Web Browser

## 📚 Topics Covered
1. Introduction to HTML
2. Basic HTML Structure
3. HTML Tags and Attributes
4. Headings and Paragraphs
5. Lists (Ordered and Unordered)
6. Hyperlinks and Images
7. HTML Tables
8. HTML Forms
9. HTML Semantic Elements

## 📂 Repository Contents
- `index.html` – HTML file containing the assignment implementation.
- `README.md` – Assignment description and documentation.

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open the `index.html` file in any web browser.
4. View the output of the HTML webpage.

## 📌 Conclusion
Through this assignment, I learned the fundamentals of HTML and how to create structured web pages using different HTML tags and elements. It helped me understand the basic building blocks of web development.
